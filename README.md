BIOGoAlS.TE\_LP tool created after the "Robust Optimization" PhD course of Politecnico di Milano by Professor Erick Delage.

See "/Project/RobustOptimization\_Project\_Proposal.pdf" for an conceptual introduction.
See "/Project/RobustOptimization\_Project\_Report.pdf" for rigorous Mathematical formulations and results' interpretations for the example case of study. 
See "/BIOGOALS.TE-LP\_USER\_MANUAL.pdf" for a Step-by-Step guidance throughout the files and the main "/Project/RO\_project.ipynb" code. 
See "MATH80624\_LectureNotes.pdf" for Mathematical theoretical details.

Note: the "/80624" folder has deprecated.

Inside the "/Project" folder:

>> Jupyter notebook code to run the BIOGoAlS TE\_LP tool (robust linear programming optimization for supply-chain-like diet optimization).
Mosek licence recommended!! If not available, add GUROBI or other open-source solvers to the python environment and modify "/Project/RO\_project.ipynb" accordingly (scipy.optimize is the default solver).

>> Supplementary pyhton functions for the Jupyter notebook to run.

>> Excel file for input data for the Jupyter notebook to run.

>> Excel file for storing output data from the Jupyter notebook.

>> Pdf files to introduce and document the code implementation example provided and the consequent results.
